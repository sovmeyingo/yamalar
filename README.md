# Neko Çeviri

Neko Launcher Türkçe yamaları oyun seçilince indirir ve doğruladıktan sonra kurar.
Yama verileri Releases bölümünde tutulur. İlk indirme için internet gerekir.
Oyun dosyaları kurulumdan önce yedeklenir; kaldırma launcher üzerinden yapılır.

Yamalar kullanıcı tarafından sağlanan çalışmalar ve Neko düzenlemelerinden
oluşur. Özgün çeviri katkıları ve üçüncü taraf lisans/bildirimleri ilgili
paketlerde korunur. Dosyalar tek tek SHA256 ile doğrulanır.
